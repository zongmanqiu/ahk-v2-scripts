# 文件解锁

文件被占用删不掉、改不了名？找出占用它的进程，确认后结束该进程即可解锁。

## 功能

- 选择或拖入一个文件、或一个文件夹（递归检查其中所有文件）。
- 一键检测：列出正在占用这些文件的进程（进程名、PID、占用文件）。
- 选中一个占用进程、确认后结束它，随即自动复查是否解锁。
- 系统关键进程（如 explorer、lsass、dwm 等）在保护名单里，会被拒绝结束。

## 入口

- 主窗口「选择路径」按钮或把文件/文件夹拖进窗口；点「检测占用」开始。
- 全局热键由 AHKDeck 统一指派，脚本不自设。
- `--selftest [输出路径]`：无 GUI 分支，默认写 `文件解锁\selftest-result.txt`。

## 写入位置

- 运行时不写配置文件；仅 `--selftest` 的结果写 `文件解锁\selftest-result.txt`（同名文件夹，不进仓库）。

## 风险与不做

- **结束进程会丢失该进程未保存的数据**——必须用户手动选中并二次确认，脚本绝不自动结束进程。
- 系统关键进程在保护名单内，拒绝结束；脚本也不会结束自己。
- 正在运行的程序主模块（exe 本身）占用无法只解不杀，只能结束进程——这是 Windows 的机制。
- 不写注册表、不联网、不读写剪贴板、不碰选区文本，不携带外部 exe。
