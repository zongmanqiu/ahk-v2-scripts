# 文件解锁

文件/文件夹被占用删不掉、改不了名，或者遇到 `nul`、`con` 这类删不掉的顽固文件？把它拖进窗口，一键解除占用或直接删除。

## 功能

- 把文件或文件夹拖进列表，自动检测占用状态，无需手动点检测。
- 列表逐项显示：路径、类型（文件/文件夹）、状态（未占用 / 被占用 · 占用进程名）。
- **解除占用**：找出正在占用选中项的进程，确认后结束它们，状态随即刷新为「未占用」。
- **删除**：永久删除选中项（不进回收站），能处理占用中文件、只读/权限受限文件，以及 `nul`、`con` 这类 Windows 保留名文件——这些文件在资源管理器里删除时误报「需要管理员权限」，本脚本能直接删掉。
- 未选中任何项时，「解除占用」「删除」作用于列表全部项。
- 系统关键进程（如 explorer、lsass、dwm 等）在保护名单里，不会被结束。

## 入口

- 主窗口：把文件/文件夹拖进列表即自动检测；不设全局热键。
- `--selftest [输出路径]`：无 GUI 分支，默认写 `文件解锁\selftest-result.txt`。

## 写入位置

- 运行时不写配置文件；仅 `--selftest` 的结果写 `文件解锁\selftest-result.txt`（同名文件夹，不进仓库）。

## 风险与不做

- **「删除」是永久删除，不进回收站，不可撤销**——必须二次确认。
- **「解除占用」会结束进程，可能丢失该进程未保存的数据**——必须二次确认，系统关键进程自动拒绝，脚本也不会结束自己。
- 正在运行的程序主模块（exe 本身）占用无法只解不杀，只能结束进程——这是 Windows 的机制。
- 不写注册表、不联网、不读写剪贴板、不碰选区文本，不携带外部 exe。
