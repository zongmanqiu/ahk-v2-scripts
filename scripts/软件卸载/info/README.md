# 软件卸载

扫描已安装程序，静默卸载并清理注册表与文件残留（Win10/11）。

## 功能

- 启动时扫描三处卸载注册表（HKLM / Wow6432Node / HKCU），列出安装记录
  （名称 / 版本 / 发行者 / 状态）。自动过滤系统组件（SystemComponent=1）与
  更新补丁条目（ParentKeyName），MSI 产品按 GUID 去重。
- 选中一项点「卸载」：按「注册表静默串 → MSI 静默（/X{GUID} /qn /norestart）→
  安装器家族静默（InnoSetup / NSIS / Squirrel，按卸载器文件判定）→ 注册表原样运行」
  决策链执行；确认框里会展示将执行的完整命令。没有已知静默参数的程序会弹出自家
  卸载界面（状态列标「交互卸载」），请在其界面里手动完成。
- 等待卸载器真正退出（Job Object 监听进程树 + 注册表条目消失 + 4 秒宽限），
  期间窗口保持响应；上限 10 分钟。
- 卸载成功后自动扫描该程序的残留：六大目录根（Program Files / Program Files (x86) /
  ProgramData / AppData / LocalAppData / LocalAppData\Programs）中的同名文件夹
  （含发行者嵌套）、三处 `Software\<名>` 注册表键、残留卸载条目；结果切到残留视图
  （路径 / 类型 / 大小 / 说明，带勾选框）。泛用名（common/data/microsoft 等）绝不
  单独匹配；与仍安装程序的目录/名字相交的候选一律排除；文件夹 >2GB 默认不勾选。
- 残留视图点「清理残留」：文件夹整棵进回收站（可还原，失败如实报错，绝不悄悄
  永久删除）；注册表键先导出 .reg 备份再整键删除；刚清空的空壳发行者文件夹顺带移除。
- 状态列「卸载器缺失」的条目可直接扫描残留（跳过本体卸载）。

## 入口

- 主窗口（可缩放，560×340 起）；全局热键由 AHKDeck 统一指派，脚本不自设。
- `--selftest [输出路径]`：无 GUI 自测（名称清洗 / 泛用名 / MSI 提取 / 卸载串解析
  三形态 / 家族判定 / 决策链优先级 / 包含判定 / 自建自清注册表键的残留匹配与备份删除），
  默认写 `软件卸载\selftest-result.txt`。
- `--report [输出路径]`：只读扫描取证（三源键数、扫描与分类耗时），默认写
  `软件卸载\report.txt`。

## 写入位置

- 全部产物进 `scripts/软件卸载/软件卸载/`（同名文件夹，运行时自建，不进仓库）：
  `selftest-result.txt`、`report.txt`、`backup\<时间戳>\<序号> <键名>.reg`。
- 本脚本执行卸载与清理时，被卸载软件自己的写入行为不归本脚本管。

## 风险与不做

- 卸载与清理均为破坏性操作：卸载前有确认框（展示完整命令）；残留清理有确认框，
  文件夹只进回收站、注册表键先备份后删（备份保留在同名文件夹下，误删可双击还原）。
- 不杀进程、不解占用（被占用的残留会如实报错，请先用《文件解锁》处理）；不改
  ACL/所有权、不动 TrustedInstaller 保护键。
- 不做 UWP/AppX/MSIX 卸载（设置页「应用」里卸载那类，v2 候选）；不用 winget 通道
  （机器可能没装 App Installer）。
- 无网络、无遥测；所有判断只读本机注册表与文件系统。
