# 文件哈希

选一个文件，一趟读出 MD5 / SHA1 / SHA256 / SHA384 / SHA512 五种校验值；双击行复制该算法，或一键复制全部。
纯 AHK v2 调系统 Advapi32 CryptoAPI，零外部 exe、零网络、零注册表。

## 功能

- 一次文件读取同时喂五个 CryptoAPI 哈希句柄（不是读五趟）：大文件只受一次 IO + 一次计算限制。
- 两种选件方式：「选择文件」按钮，或把文件**直接拖进窗口**（拖多个只算第一个并如实提示）。
- 每行结果：算法名 · 小写十六进制 · 状态；双击复制到剪贴板，状态栏报实际字符数。
- 「复制全部」一次带走五行（含算法名，可直接粘去比对官网校验值）。
- **失败隔离、不假成功**：某算法在本机不可用时（极老系统缺 SHA-512 等），该行状态列如实标
  「算法不可用（错误码 …）」，其余算法照常出结果；文件打不开则整趟拒算并明说。
- 计算中状态栏滚动进度（已读 MB）。
- 界面所有文字固定高度垂直居中；按钮/列头/状态条为纯色块自绘，系统标题栏由 DWM 染成同色，
  在宿主与独立运行下观感一致。窗口内不设重复的算法说明带。
- 输入框与结果列表去掉系统 3D 凹陷边框，改 1px 扁平细线 + 白底；输入框文字左右留内边距。
- 输入框文字用 `ES_MULTILINE + EM_SETRECT` 真正垂直居中，与同排按钮文字同基线；
  去掉系统自动附加的垂直滚动条与回车换行，长路径仍走横向滚动。
- 表头与列表框严格等宽、三列文字对齐；输入框与按钮同高同起点。

## 入口

- 主窗口即入口：宿主内运行直接弹窗，**窗口关闭即退出**；独立运行同样直接弹窗。
- 本脚本不注册托盘菜单、不自设全局热键；全局热键如需可交给 AHKDeck 指派。
- 命令行分支（无 GUI）：
  - `--selftest [输出路径]`：黄金向量/确定性/单趟一致/拒算/失败隔离等 11 组断言，
    只建 %TEMP% 自创临时文件、结束即删，`rc=0` 全绿。

## 写入位置

- 无：不写注册表、不改文件、无同名 ini；`--selftest` 的结果文件路径由命令行指定。
- 计算是纯读操作，不改动被哈希文件的任何属性。

## 风险

- 超大文件计算期间窗口暂时无响应（单线程一趟读，属预期），完成即恢复；4 GB 级一般为分钟量级。
- SHA-1/MD5 已不适合安全场景，作下载完整性校验与指纹比对够用——界面输出五值并列，用途由使用者判断。

## 不做

- 不做文件夹批量/递归校验清单；不做两文件比对判定；不做 HMAC/xxhash/哈希算法自扩；
  不做联网校验或下载文件（零网络）；不做"校验失败替你删文件"之类的破坏动作。
- **不做 CRC32**（1.1.0 评估过）：CryptoAPI 的 `CALG_CRC32` 在 AES/FULL 两个提供方下
  `CryptCreateHash` 均报 `NTE_BAD_ALGID`（探针实测）；纯 AHK 逐字节查表约 10 MB/s，
  会拖垮"一趟读"的性能卖点，判不达准入。ZIP/RAR 内嵌 CRC 请用压缩工具查看。
