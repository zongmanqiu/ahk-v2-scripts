# 打开方式清理

扫描 Windows「打开方式」相关的 13 处注册表位置，列出并清理失效残留。

复刻自同作者的 C# 项目 OpenWithCleaner（WinForms），注册表扫描口径一致，界面用纯 AHK v2 重写，只中文。
不含原项目的关于页、打赏二维码、多语言与自动更新（自动更新会覆盖宿主目录，不能照搬）。

## 功能

- **扫描**：13 处来源（用户/系统 FileExts、Applications、Classes、全局 MRU/ProgId、App Paths、
  RecentApps、商店包 Repository、Launch 契约、Clients 等），按注册表位置去重；分 15 步异步扫描，界面不冻。
- **列表**：真勾选框；隔行底色；状态列彩色加粗（有效=绿／未找到=橙／未知=灰）；点表头**原地排序**
  （comctl32 内部重排，不删行不重建，勾选/焦点/滚动保持）；搜索防抖 250 ms，匹配扩展名/程序/显示名称/来源/注册表路径/状态中文；
  `Delete` 键删除勾选行。
- **操作**：刷新、全选、删除失效项、复制路径（工具栏／双击行／右键菜单）、删除选中、历史记录。
  删除与全选**原地更新列表**，不重扫、不整表重建，滚动位置与焦点保持。
- **删除与备份**：删除前自动备份到脚本旁 `打开方式清理\history\backup_时间戳.txt`；
  HKCR 条目先试 `HKCU\Software\Classes` 再试 `HKLM\SOFTWARE\Classes`；失败条目提示提权
  （提权经宿主 `--run` 或独立解释器重启本脚本）。
- **恢复**：历史窗可查看/恢复备份。**有损**：备份只记程序路径，恢复一律写回 REG_SZ，
  不还原原始值类型与 MRUList 顺序（与原项目一致）。

## 入口

- 托盘菜单「打开方式清理」（宿主内由宿主镜像；独立运行显示自己的托盘图标）。
- 命令行分支（无 GUI）：
  - `--report [输出路径]`：只读扫描，输出逐来源行数/耗时等读数。
  - `--selftest [输出路径]`：合成注册表键自测（删除→备份→恢复→原地摘行→原地排序），只动自建键、结束即清理；rc=0 全绿。

## 写入位置

- 删除：上述 13 处注册表位置里的「打开方式」候选值/子键（**不改默认关联**）。
- 备份：脚本旁 `打开方式清理\history\backup_时间戳.txt`。

## 权限

- 普通权限可删 HKCU 条目；HKLM 条目需管理员。本工具只删「打开方式」候选，不改默认关联。

## 已知数据问题

- 个别程序的显示名称在注册表里本身就是乱码（安装器把 UTF-8 当 ANSI 写入），本工具与原项目一样如实显示，不做修复。

## 与原项目的差异

- 复制路径改为工具条按钮与双击行；新增「删除失效项」。
- 扫描结果按注册表位置去重（原项目把 HKCU 的扩展名重复计入两次）。

## 不做

- 关于页、打赏二维码、多语言、自动更新、「修复系统关联」、乱码修复。
