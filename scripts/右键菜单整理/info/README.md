# 右键菜单整理

右键菜单用久了会被各种软件塞满。这个脚本列出每个位置的全部菜单项——既有系统/软件装进注册表的静态项，也有 7-Zip、ima、360、Unlocker 这类 COM 扩展——逐项**隐藏**掉你不想要的，或者把常用的**置顶**——只写当前用户（HKCU），随时能恢复原样。

## 功能

- 左侧选位置：文件、文件夹、文件夹空白处、驱动器、文件夹对象、所有对象、桌面背景，共七处；外加**按扩展名**——输入 `.md` / `md` 这类后缀，列出该类型专属的菜单项。
- 右侧列出该位置的**全部**菜单项，四列显示：
  - **菜单项**：显示名称解析成人话，`@shell32.dll,-8506` 这类间接串会转成可读文字。
  - **来源**：`静态`（注册表 verb）或 `COM`（shellex 扩展）。
  - **状态**：**显示** / **已隐藏**（本脚本隐藏的）/ **系统隐藏**（HKLM 里带隐藏标记，零提权删不掉）。
  - **位置**：默认 / 置顶 / 置底（COM 项由 DLL 动态绘制，不支持位置，显示 `—`）。
- 选中一项后可：
  - **隐藏 / 显示**：静态项写隐藏标记；COM 扩展按 CLSID 加入/移出 Blocked 黑名单，全局生效。
  - **置顶 / 置底 / 恢复位置**：调整静态项在右键菜单里的排列位置。
- 改完立即广播 `SHChangeNotify`，绝大多数情况不用重启资源管理器。

## 入口

- 主窗口：左侧选位置或填扩展名 → 右侧选菜单项 → 底部按钮操作。
- `--selftest [输出路径]`：无 GUI 分支，默认写 `右键菜单整理\selftest-result.txt`。
- `--probe verb <位置suffix> <verb> <动作>` / `--probe com <CLSID> <hide|show>`：实机回归用，直接驱动同一套写函数；日常不用。

## 写入位置

只写 HKCU，HKLM 原键一个字节都不动：

- **静态项隐藏**：`HKCU\Software\Classes\<位置>\shell\<菜单项名>` 写 `ProgrammaticAccessOnly = ""`；恢复即删这个值。
- **静态项位置**：同键写 `Position = top / bottom`；恢复默认即删这个值。位置根不含 `\shell`（如 `*` / `Directory\Background`）。
- **COM 扩展隐藏**：`HKCU\Software\Microsoft\Windows\CurrentVersion\Shell Extensions\Blocked` 写一个值名为 CLSID 的空串；恢复即删该值。

这些值在 `HKCR` 合并视图里可见，于是既能盖住 HKLM 的菜单项，又不破坏它原本的显示名和命令。
`--selftest` 结果写 `scripts/右键菜单整理/右键菜单整理/selftest-result.txt`（同名文件夹，运行时自建，不进仓库）。

## 风险与不做

- **不永久删除**任何菜单项、不改命令、不碰文件关联、不提权、不写 HKLM。隐藏和位置都是可逆的。
- **系统级隐藏的项恢复不了**：若某项的隐藏标记写在 HKLM（如 `HideBasedOnVelocityId`），零提权删不掉，脚本会如实提示"需管理员权限"，绝不谎称已恢复。
- **系统共享的 COM 扩展拒隐藏**："共享 / 投射到设备 / 还原以前的版本 / 照片编辑 / 包含到库中" 这类 CLSID 由多个功能共用，Blocked 会连带弄坏系统菜单，脚本一律拒写。7-Zip、ima、360、Unlocker 这类独立扩展不受限。
- **不碰 `open` / `edit` 这类打开动词**：它们是文件关联的关键，脚本对这两个 verb 一律不写。
- **不写 `CommandFlags`**：那是 Windows 的功能位掩码，不是开关，写错会弄坏菜单；本脚本只读取它来判断是否已隐藏。
- **不做 Win11 打包命令（IExplorerCommand）**：那是稀疏 MSIX 包 manifest 里的动态命令，不属于注册表静态项，本脚本不覆盖。
- 菜单项显示名取自注册表；个别项的中文名由系统资源串解析，解析不出来时回退为注册表名。
