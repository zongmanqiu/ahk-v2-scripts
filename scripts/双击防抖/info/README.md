# 双击防抖

用低级鼠标钩子拦截间隔过短的双击/连点，抑制误触。左键、右键、中键各自独立开关与间隔（10–500 ms），
可在托盘设置里分别配置。

曾用名「鼠标左键双击最小间隔」，1.0.0 起改现名，行为不变。

## 功能

- 低级鼠标钩子（`WH_MOUSE_LL`）：同一键两次按下间隔小于该键设定值时，吞掉第二次按下及其抬起；
  左键、右键、中键各自判定、互不影响。
- 带注入标记（`LLMHF_INJECTED`）的事件不拦截——只防物理误触，不影响脚本/远程注入的点击。
- 托盘「设置」：左/右/中三键各自设间隔 10–500 ms，默认 50 ms；`0` = 关闭该键的防抖；保存即生效。
- 退出时卸钩；钩子安装失败会弹窗报错并退出，不静默失效。

## 入口

- 托盘菜单「设置」（宿主内由宿主镜像成右键子菜单；独立运行显示自己的托盘图标）。
- 无热键、无命令行分支。

## 写入位置

- 配置：脚本旁的同名文件夹 `双击防抖\双击防抖.ini`（`[Settings]` 下 `Left` / `Right` / `Middle`，
  单位毫秒，`0` = 关闭该键）。旧版把 ini 摊在脚本旁，首次启动会自动整份复制到新位置，
  旧文件保留不动（回退旧版时设置还在）。不写注册表、不写宿主目录。

## 风险

- 全局鼠标钩子会影响**所有程序**的左/右/中键双击手感；间隔设得过大可能让正常双击失效。
- 钩子随脚本退出卸载；脚本被强杀时钩子由系统回收。

## 不做

- 不改系统双击速度（`SPI_SETDOUBLECLICKTIME`）；只在钩子层吞事件。
- 不做连点加速（只做防抖）；三键均可通过设为 `0` 单独关闭拦截。
