# 双击防抖 历史

只增不改：每次发版在最上面加一段 `## <版本>（日期）`。

## 1.2.0（2026-11-13）

- **去掉底部那一行说明**（1.1.0 加的「间隔 50 ms」状态条）。窗口变高不是留了状态条，
  而是改成了三行输入：客户区 `332×110 → 332×150`，
  `顶 12 + 28 + 4 + 28 + 4 + 28 + 6 + 28 + 底 12 = 150`。
- **名字与功能对齐**：1.1.0 只拦左键，UI 却写通用的「连击最小间隔」，名实不符。
  两个选项里取「把其它按键也做了」：保持文件名 / 文件夹名 / `@name` 不变
  （不破坏 `.ini` 路径、分发清单与宿主镜像菜单），把钩子改成**一套通用逻辑 +
  键位/间隔参数表** —— 左/右/中键（`0x201/202`、`0x204/205`、`0x207/208`）
  各自独立记 `last` / `blocked`，互不串味；描述与窗口标签逐键写明键位。
- **配置**：`[Settings] Left/Right/Middle`，`0` = 关闭该键，`10~500 ms` = 启用。
  旧 `Interval` 首次启动迁移到 `Left` 后删除，右键/中键默认 0，旧行为完全保留；
  实测 `Interval=75` → `Left=75 / Right=0 / Middle=0`（`.temp/probe_dbl_ini.py`，PASS）。
  保存时重置三键 `last`/`blocked`，避免改间隔后残留一次被吞的抬起。
- **对齐**：三行输入框统一 `x204 w112`（右缘 316），操作行两按钮右对齐到同一个 316，
  输入框与按钮组共用右边界；行内 `180+8+112=300`（行宽 300），不再左右错位。
- **未做真机鼠标拦截探针**：三键拦截由代码结构 + 静态门禁 + ini 迁移实证覆盖，
  真实鼠标连点拦截留给作者手测（全局钩子不便在自动探针里安全观察）。
- **门禁**：解释器 `/validate` rc=0；宿主 `--validate` `{"ok":true,"rc":0}`；
  独立 + 宿主 `--run` 双环境 9/9 像素命中（窗口由真源副本末尾直调 `ShowSettings()` 拉起）。

## 1.1.0（2026-11-13）

- **按 开发指南 §10 统一设置框**。旧版是 `MarginX/Y 14` 自动布局 + 系统
  `Button`/`Edit` + 默认配色，宿主内退回经典 3D 样式。
- **坐标**：客户区 `332×110`，行宽 `300`（332−16×2）；字段行
  `164+8+112=300`（`x16 / x188`）、`y12 h28`；操作行 `y46 h28`，两按钮各 `58`
  （两字 + 左右各 16）、整组右对齐到 `316`；状态条 `y80 h30`、窗高 `110=80+30`。
- **令牌**：`BG` / `SOFT` / `BAND` / `FRAME` / `TEXT` / `WHITE` 六色，
  `s10 Microsoft YaHei UI`；`FlatButton()` 1px 描边不分主次；Edit 用
  `Multi -VScroll -WantReturn -Wrap -E0x200` + `EM_SETRECT(8,2,104,26)`；
  `PaintCaption()` 把标题栏染成 `#DCE8F7`。
- **例外（如实登记）**：系统 Button 的 `Default` 选项随按钮一起消失，回车不再
  提交，改由点击「保存」；§10.5 没有 Text 色块按钮的 Default 配方，不为它破例
  引回系统控件。MsgBox 是系统对话框、不属 §10 适用范围，错误文案保持原样。
- **行为**：`WH_MOUSE_LL` 钩子、注入标记放行、ini 读写、10–500 ms 校验、
  退出卸钩全不动。
- **门禁**：解释器 `/validate` rc=0；宿主 `--validate` `{"ok":true,"rc":0}`。
- **实机像素**（独立 + 宿主 `--run` 各一张 PNG，探针在末尾直调 `ShowSettings()`）：
  窗口 `348×149`、客户区偏移 `8,31`；9 个取样点两环境逐点一致 —— 标签
  `F7F9FC`、输入框帧 `B7C8E0` / 框内 `FFFFFF`、两按钮外块 `B7C8E0` /
  内块 `EBF2FB`、状态条三点 `DCE8F7`，**9/9 命中**。

## 1.0.0（2026-11-11）

- 首次发布：低级鼠标钩子（`WH_MOUSE_LL`）吞掉间隔过短的左键按下及其抬起，抑制误触双击/连点；
  带注入标记的事件不拦截。
- 托盘「设置」调间隔 10–500 ms（默认 50 ms），存于脚本旁同名 `.ini`；退出卸钩，装钩失败弹窗报错退出。
- 由「鼠标左键双击最小间隔」改现名（文件夹/文件名/`@name`/同名 ini/窗口与托盘标题同步），行为不变。
