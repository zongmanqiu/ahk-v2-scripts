# 文件时间修改

拖入文件或文件夹，按设定好的时间一次改写它们的创建、修改、访问时间。

## 功能

- 三种时间各自独立：每行一个启用勾选，加日期框（年/月/日）与时分秒框（时/分/秒），可设不同值；取消勾选即该项不改。
- 拖放是唯一添加方式，可一次拖入多个文件或文件夹，路径列表带垂直与水平滚动条。
- 默认只改拖入项本身；勾选「包含子文件（夹）」后，文件夹连同内部所有层级的文件与子文件夹一起生效，状态栏会额外显示展开后的总数。
- 只有点「更新时间」才真正写入；状态栏显示带时分秒前缀的成功/失败数，便于区分连续多次操作。拖入不落盘。
- 「清空列表」清空待处理路径。

## 入口

- 主窗口「更新时间」按钮；把文件/文件夹拖到窗口任意位置即加入列表。
- 无托盘菜单、无全局热键、无命令行分支。宿主启动后直接弹窗，独立运行同样直接弹窗；窗口关闭即退出。

## 写入位置

- 只改写拖入的文件/文件夹自身的三个时间戳（Windows 文件系统属性）。不写注册表、不写脚本旁 ini、不写宿主目录、不产生备份或日志文件。
- 不改动文件内容、名称与位置。

## 风险

- 时间戳改动不可逆，脚本不提供备份或撤销；重要文件请先自行备份。
- 文件夹的「访问时间」写入后若又被系统枚举/访问，Windows 会自动把它刷新成当前时间（文件不受影响）；读回值与设定值不同不代表写入失败。
- 写入失败会按项计入失败数并在状态栏显示，不静默跳过、不中断整批。

## 不做

- 不做随机/偏移/复制参考文件等时间来源，不做扩展名、大小、天数筛选，不做模拟预览。
- 不改文件内容、属性位与权限；不提供自动更新或在线下载。
- 不注册托盘菜单与全局热键（全局热键由 AHKDeck 统一指派）。
