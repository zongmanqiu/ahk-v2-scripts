# 防休眠 历史

只增不改：每次发版在最上面加一段 `## <版本>（日期）`。

## 1.0.1（2026-11-13）

- **按 开发指南 §10 核对：不适用**。本脚本只有托盘菜单，没有任何 `Gui()`
  原生窗口；§10.1 明确把「托盘菜单、无 GUI 脚本」排除在适用范围外，
  故界面零改动，不硬套列头/状态条/按钮配方。
- **文案核对**：`阻止系统休眠` / `阻止屏幕关闭` / `退出` 都是 2–4 字动词短语，
  `A_IconTip` 用 `·` 连接状态事实、不写指令句，与 §10.6 口径一致，无需改字。
- **功能零改动**：`SetThreadExecutionState` 位组合、失败回滚、退出清回、
  `Persistent(true)`、`--selftest` 全不动；本版本只做标准落点登记。
- **门禁**：解释器 `/validate` rc=0；宿主 `--validate` `{"ok":true,"rc":0}`；
  `--selftest` 6 项 PASS、`fails=0`、rc=0。
- **无像素项**：本脚本不创建任何窗口，§10.11 的截图复核不适用。

## 1.0.0（2026-11-12）

- 首次发布：两项托盘勾选（「阻止系统休眠」`ES_SYSTEM_REQUIRED`／「阻止屏幕关闭」`ES_DISPLAY_REQUIRED`），
  基座 `ES_CONTINUOUS`，直接调用 `kernel32\SetThreadExecutionState`；不模拟按键、不设定时器、无热键。
- API 调用失败即回滚本次勾选并弹窗报错（附错误码），不假成功；勾选状态即生效状态。
- 退出（含宿主停止本脚本）显式清回 `ES_CONTINUOUS`，把电源策略交还系统默认。
- 纯托盘脚本无其他常驻理由，按开发指南 §4 显式 `Persistent(true)` 声明常驻。
- 带 `--selftest [输出路径]` 无 GUI 分支：四组开关位组合纯计算校验 + 真实 API「全开→清回」往返，
  结束即清回，`rc=0` 全绿。
