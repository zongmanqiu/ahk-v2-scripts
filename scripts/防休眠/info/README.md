# 防休眠

两项托盘勾选：阻止系统休眠、阻止屏幕自动关闭。直接调用内核 API `SetThreadExecutionState` 申请
常驻唤醒，不模拟按键、不设定时器；脚本退出即交还系统默认电源行为。

## 功能

- 「阻止系统休眠」：勾选后接通 `ES_SYSTEM_REQUIRED`，系统不因空闲自动进入睡眠。
- 「阻止屏幕关闭」：勾选后接通 `ES_DISPLAY_REQUIRED`，屏幕不再自动熄灭。
- 两项独立可组合；再点一次即取消对应档。全关时脚本对系统不做任何干预。
- 菜单勾选与图标提示（独立运行时）即当前生效状态，无隐藏开关；API 调用失败会回滚勾选并弹窗报错，不假成功。

## 入口

- 托盘菜单「阻止系统休眠」／「阻止屏幕关闭」／「退出」（宿主内由宿主镜像；独立运行显示自己的托盘图标）。
- 全局热键由 AHKDeck 统一指派，脚本不自设。
- **关掉提示消息不会退出脚本**：脚本本身常驻待命，托盘入口随时可用；要停止请点「退出」。
- 命令行分支（无 GUI）：
  - `--selftest [输出路径]`：校验四组开关位组合的纯计算，并对真实 API 做「全开 → 清回」往返；
    只动本线程执行状态、结束即清回，`rc=0` 全绿。

## 写入位置

- 无：不写注册表、不写文件、不改电源计划（`--selftest` 的结果文件路径由命令行指定，默认脚本旁）。

## 退出行为

- 退出（含宿主停止本脚本）时显式清回 `ES_CONTINUOUS`；即使进程被强杀，系统也会在所属线程结束时
  自动失效该状态，不会留下"看不见却在防休眠"的残留。

## 风险

- 「阻止屏幕关闭」常开在笔记本上更耗电；长时间静止画面显示有烧屏风险——由使用者自行权衡，脚本不做自动超时。

## 不做

- 不做定时自动开启/到期关闭；不做"模拟按键骗过去"（会干扰前台程序）；不做插电/电池策略分档；
  不做 Away Mode（`ES_AWAYMODE`）；不做多显示器分别控屏。

## 来源

- 独立实现，未复刻第三方源码。思路对照 Caffeine 一类常驻唤醒工具的公开原理：
  kernel32\SetThreadExecutionState（`ES_CONTINUOUS` / `ES_SYSTEM_REQUIRED` / `ES_DISPLAY_REQUIRED`）。
